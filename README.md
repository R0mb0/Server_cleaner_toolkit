# Server_cleaner_toolkit
Interactive PowerShell CLI for Windows Server 2016+ that finds and safely deletes files across every drive and web cache (IIS, ASP.NET, XAMPP/WAMP). Tolerant fuzzy name matching, colorized session logs, confirm-before-delete safety, and a UI in 6 languages (EN, IT, FR, DE, ES, PT). Single portable script, no install needed.
